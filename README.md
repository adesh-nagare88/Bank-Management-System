Bank Management System — C++

A console-based Bank Management System developed in C++ to simulate core banking operations while demonstrating Object-Oriented Programming (OOP), file handling, and STL concepts.

### Features

* Create and manage customer accounts
* Deposit and withdraw funds
* View and manage account details
* Menu-driven console interface for easy navigation
* Store and retrieve account data using file handling
* Manage multiple accounts efficiently using **STL vectors**
* Persistent data storage to retain account information between program executions

### Technologies & Concepts

* Language: C++
* Concepts: OOP, File Handling, STL, Data Management
* STL: Vector
* Interface: Console-based / Menu-driven
